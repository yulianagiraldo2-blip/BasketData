# BasketData
Aplicación académica de análisis de partidos NBA y juego de identificación de jugadores.

## Ejecutar en Windows
Desde PowerShell, dentro de BasketData:
```
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run Inicio.py
```
Fuente: https://www.kaggle.com/datasets/nathanlauga/nba-games. Verificar licencia antes de publicar datos originales o derivados. El notebook requiere Jupyter como herramienta de ejecución.
