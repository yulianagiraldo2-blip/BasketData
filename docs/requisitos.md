\# Especificación de requisitos — BasketData



\## 1. Objetivo general



Desarrollar una aplicación interactiva que permita explorar datos históricos de la NBA y fortalecer el conocimiento deportivo mediante un juego de identificación de jugadores basado en estadísticas reales.



\## 2. Requisitos funcionales



| Código | Requisito |

|---|---|

| RF01 | Presentar la información general del proyecto. |

| RF02 | Cargar y visualizar datos deportivos reales. |

| RF03 | Permitir el filtrado de partidos. |

| RF04 | Presentar estadísticas y gráficos dinámicos. |

| RF05 | Generar preguntas utilizando datos reales de jugadores. |

| RF06 | Permitir seleccionar tres niveles de dificultad. |

| RF07 | Calcular la puntuación del usuario. |

| RF08 | Informar si una respuesta es correcta o incorrecta. |

| RF09 | Permitir reiniciar el juego. |

| RF10 | Registrar el historial y progreso durante la sesión. |



\## 3. Requisitos no funcionales



\- Interfaz intuitiva y organizada.

\- Diseño visual coherente con la temática deportiva.

\- Compatibilidad con Python 3.12.

\- Acceso mediante navegador web.

\- Código modular y mantenible.

\- Manejo de errores durante la carga de datos.

\- Control de versiones mediante Git y GitHub.



\## 4. Requisitos de datos



\- Utilizar una base de datos real con más de 1.000 registros.

\- Conservar los archivos originales en data/raw/.

\- Realizar la limpieza mediante Jupyter Notebook.

\- Almacenar los datos procesados en la carpeta data/.



\## 5. Validación



El proyecto cuenta con seis pruebas automatizadas para verificar la sintaxis, los datos de partidos, los datos de jugadores, los filtros, la lógica del juego y el control de errores.



Las seis pruebas fueron superadas correctamente.
